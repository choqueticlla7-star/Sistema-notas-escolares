# 📚 Sistema de Notas Escolares

Sistema web para consulta de calificaciones estudiantiles.

## 🎯 Características
- Consulta de notas por código estudiantil
- Panel administrativo para gestión de calificaciones
- Gráficos interactivos
- Diseño responsive
- Modo oscuro

## 🛠️ Tecnologías
- HTML5
- CSS3
- JavaScript
- Chart.js
- JSON
